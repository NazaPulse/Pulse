# Reglas Globales del Proyecto Pulse
- Nunca modifiques ni elimines archivos fuera del directorio de trabajo asignado.
- Queda prohibido ejecutar comandos destructivos en terminal (rm -rf, drop DB) sin confirmación previa.
- Toda API debe respetar estrictamente la estructura y tipos de datos de `openapi.yaml`.
- La base de datos PostgreSQL debe ser la única fuente de verdad compartida.
- Antes de dar por terminada una tarea, ejecuta los tests del directorio actual.
